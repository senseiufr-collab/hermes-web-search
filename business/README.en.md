# Business Scan Docs

This module turns generic web search into a business intelligence scan.
It uses category-based dorks and lightweight classification to surface market, competitor, client, partnership, regulation, and funding signals.

## Commercial use
- Best paired with a Google CSE backend or a hosted search API
- Can be wrapped into a paid skill, hosted report service, or internal analyst tool
- Recommended pricing: $29–149/month for automated niche scans; $100–500 for one-off reports
