# Business Scan Docs

Модуль превращает обычный веб-поиск в бизнес-разведку.
Использует категорийные дорки и легкую классификацию сигналов: рынок, конкуренты, клиенты, партнерства, регуляторика, funding.

## Коммерческое использование
- Лучше работает с Google CSE или hosted search API
- Можно упаковать в платный навык, hosted-сервис отчетов или внутренний инструмент аналитика
- Рекомендуемые цены: $29–149/мес за автоматические сканы ниши; $100–500 за разовый отчет
