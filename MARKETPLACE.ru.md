# Hermes Web Search — для маркетплейса

## Короткое описание
Превращает Hermes Agent в бизнес-ассистента по поиску сигналов: рынок, конкуренты, клиенты, регуляторика, инвестиции. Кэш, дорки, JSON/CSV, Google CSE.

## Длинное описание
Hermes Web Search — централизованный CLI и skill для Hermes Agent на macOS:

- Поиск через Bing, DuckDuckGo, опционально Google CSE
- Дорки: site, filetype, intitle, inurl, exact, related
- Бизнес-сканер: категорийный анализ с автоклассификацией
- Кэширование, экспорт, shell aliases `hsearch` / `hscan`

Используется для:
- исследования ниш
- мониторинга конкурентов
- поиска клиентов
- проверки регуляторики
- поиска инвестиционных сигналов

## Преимущества
- Работает автономно благодаря кэшу
- Автоматическая классификация бизнес-сигналов
- JSON/CSV для интеграций
- Установка за 1 команду

## Примеры
```bash
hsearch "AI" -n 5
hsearch "PDF" --dork site arxiv.org --dork-value arxiv.org -n 10
hscan "local AI" -n 3 -c market,competitors,clients --csv
```
