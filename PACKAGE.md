# Product Package — Hermes Web Search

## What is included
- search.py — CLI search engine with Bing/DuckDuckGo/Google CSE and dorks
- business/scan.py — business intelligence scanner with auto classification
- hsearch / hscan — shell wrappers
- install.sh — one-line installer for macOS/Linux
- requirements.txt — pinned dependencies
- README.md / README.ru.md — public docs
- business/README.en.md / business/README.ru.md — business module docs
- MARKETPLACE.md / MARKETPLACE.ru.md — marketplace listing copy
- LICENSE — MIT
- examples/business-scan-demo.sh — runnable demo
