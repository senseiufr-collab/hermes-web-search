# Hermes Web Search

Centralized web search and business signal scanner for macOS.

- Docs: [README.md](https://github.com/senseiufr-collab/hermes-web-search/blob/main/README.md)
- Business module: [business/README.en.md](https://github.com/senseiufr-collab/hermes-web-search/blob/main/business/README.en.md)
- Release: [v0.1.0](https://github.com/senseiufr-collab/hermes-web-search/releases/tag/v0.1.0)

## Install
```bash
cd /path/to/web-search
bash install.sh
source ~/.zshrc
```

## Quick start
```bash
hsearch "AI" -n 5
hscan "local AI" -n 3 -c market,competitors,clients --csv
```
